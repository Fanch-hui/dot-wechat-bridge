# 微信绑定与接入服务

部署者自己的 Sites 项目保存权威成员、消息、游标、会话及绑定状态；一个 Node.js 22.13+ 接入服务负责各成员的微信长轮询及 MCP Events HTTPS 回调。服务无需入站端口、Redis 或额外数据库。

## 准备

1. 安装自己部署的私有 Sites 插件，由所有者在 ChatGPT 调用 `wechat_bridge_status` 完成管理身份登记。
2. 按[部署说明](deployment.md)配置 `BRIDGE_TOKEN` 和私有 Sites 访问凭据 `SITES_ACCESS_TOKEN`。将配置范本复制到受限运行目录；配置、凭据及日志权限为 `0600`，目录为 `0700`。
3. 执行 `npm run gateway -- run`，或指定配置文件：`npm run gateway -- run /etc/dot-wechat-bridge/gateway.json`。服务可以在尚无微信绑定时运行。
4. 重新扫描插件工具目录，为 Dot 配置[多人处理指令](dot-instructions.md)和 `conversation=all` 订阅。第二个微信绑定及恢复启用要求有效的 all 订阅。

微信凭据由成员扫码生成，程序不读取原有微信客户端账号数据。私有 Sites 请求使用 `OAI-Sites-Authorization`；接入 Secret 不充当网页管理员身份。

## 网页管理成员

用所有者 ChatGPT 账号打开私有 Site 首页。成员列表展示称呼、连接状态、最近来信和发送异常；支持添加、改名、重新扫码、停用及恢复。

1. 点击添加，填写成员称呼。称呼由所有者管理；重名会附短 ID，稳定成员 ID 不随改名变化。
2. 点击连接微信，页面展示该成员的专属二维码。可直接扫码或下载 PNG 后转给对应成员。
3. 页面展示等待扫码、已扫码、需要验证码、连接成功、过期或失败状态。手机出现数字时，在当前页面提交验证码。
4. 本次等待最长 5 分钟；过期或失败后点击重新获取二维码。取消绑定后，该请求不能被迟到的扫码结果激活。
5. 连接成功后服务自动开始收发该成员消息，无需为每人启动服务。

扫码确认返回的微信身份与稳定成员 ID 绑定。消息正文中的自称不能修改身份。已绑定成员重新扫码只接受同一微信，换成另一个人的微信需要新增成员；同一个微信不能分配给两个成员。

停用会停止新处理和后续发送，取消进行中的绑定并使会话租约失效；历史、待处理消息及发件任务保留。正在发送的任务保留实际结果。恢复后继续处理；失败或未知结果仍须人工解决。

## 运行与凭据

所有成员共用一个全局网关租约，接入协议版本为 2。每个微信独立轮询、游标、恢复日志和发送队列，一人的凭据过期或发送异常不阻塞其他人；全局服务负责心跳与事件回调。

运行目录使用 `participants/<成员 ID>/` 保存凭据和恢复日志，`bindings/<绑定 ID>/` 保存绑定恢复信息。扫码凭据先原子暂存，服务端确认相同 binding ID 后才激活；服务重启按权威绑定状态恢复。目录必须持久保存，不能通过清空日志解决故障。

旧版本根目录的 `wechat-credentials.json` 和 `gateway-journal.json` 保留兼容，归属原 `personal` 成员。旧命令 `npm run gateway -- bind` 仅用于原成员兼容；新增成员使用网页。

Linux 参考 `deployment/gateway.service.example`，以专用非管理员用户运行。macOS 使用 launchd 或已有进程管理器。长轮询默认 35 秒，控制与心跳循环默认 1 秒；长轮询不会阻止心跳。用 `SIGTERM` 或 `Ctrl+C` 正常停止。

## 恢复与消息能力

- 收件批次及旧/新游标先原子写入该成员日志，Sites 确认后才清除；重传按成员及上游消息 ID 去重。游标冲突保留日志并暂停受影响成员。
- 发件先记录进行中状态，结果持久化后再确认。重启重传已保存结果；只有正在发送却无结果的任务标为 `unknown`，不自动重复发送。
- 发送超时显示“发送超时”；失败显示已隐藏凭据的具体原因。用户检查实际收件后决定 retry 或 skip，`unknown` 重试需接受重复发送风险。
- 腾讯 `-14` 使对应成员进入 `credential_expired`。在网页为该人重新扫码；其他成员及事件回调继续运行。
- 全局租约失效会停止服务；修复 Site 访问或网络后重启，保留运行目录。

入站支持文本、已有语音转写、图片和文件。图片与文件下载、解密后将原始字节保存在 R2，Dot 通过附件工具读取；单个附件上限 20 MiB。视频及无转写语音保留媒体提示。回复为文本。二维码重定向及登录 API 仅接受受信的 `weixin.qq.com` HTTPS 域名。

真实微信收件、Dot 唤醒和多人连续对话按[人工验收](manual-acceptance.md)确认。自动化测试不能替代真实客户端或网页交互验收。
